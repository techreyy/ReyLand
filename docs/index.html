FAQ

Pertanyaan umum

Lewat Microsoft Store atau file installer?

Isinya sama. Microsoft Store paling praktis dan tanpa peringatan SmartScreen; ukurannya lebih besar karena .NET 8 sudah ikut di dalamnya. File installer lebih kecil (±4 MB) dan memasang .NET 8 sendiri kalau belum ada. Pasang salah satu saja, karena keduanya tidak bisa berjalan bersamaan.

Muncul "Windows protected your PC"?

Itu peringatan SmartScreen untuk aplikasi baru yang belum punya sertifikat berbayar, bukan virus. Klik More info, lalu Run anyway. Peringatan ini tidak muncul kalau kamu memasang dari Microsoft Store.

Bagaimana cara memakainya?

Arahkan kursor ke island untuk membuka tab-tabnya. Scroll di atas island untuk volume, klik dua kali untuk play/pause, dan geser ke samping untuk pindah tab. Pengaturan dibuka lewat ikon ReyLand di tray.

Jadwal sholatnya dari mana?

Dihitung langsung di laptopmu dengan kriteria Kemenag, tanpa internet. Pilih daerahmu saat pertama dibuka atau di Pengaturan: ada 514 kabupaten/kota di Indonesia dan 56 kota di Malaysia.

Bisa lihat lirik sambil main game?

Bisa. Nyalakan Musik saat layar penuh di Pengaturan › Perilaku. Game harus memakai mode borderless (windowed fullscreen).

Perlu akun? Dataku disimpan di mana?

Tidak perlu akun. Pengaturan, to-do, dan agenda tersimpan di laptopmu. Detailnya ada di kebijakan privasi.
